# Statiscal Data Science Projects
  - Project 1: World Happiness Report: Statistical Analysis and Data Visualization

This project provides an in-depth analysis of the World Happiness Report dataset, focusing on key indicators such as social support, healthy life expectancy, generosity, and freedom to make life choices. The analysis begins with a statistical summary of the dataset, including metrics like mean, sum, common values, and median for each indicator. Key relationships between variables are explored, particularly between social support and generosity.

A heat map is used to visualize the correlations between various countries’ happiness scores and these indicators. Additionally, a scatter plot showcases the relationship between freedom to make life choices and generosity. The analysis also includes a line scatter plot, which illustrates how countries with high social ladder scores tend to have better social support systems.

A seaborn access grid highlights the statistical breakdown of life expectancy and healthy life expectancy across countries, providing a visual understanding of these global health indicators. Through this project, key trends and insights are drawn from the data to better understand the global landscape of happiness and well-being.
